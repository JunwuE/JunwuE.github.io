# Junwu E - Personal Website

Single-page academic homepage built with vanilla HTML/CSS, hosted on GitHub Pages.

Based on the academic-homepage-template layout.

## Sections

- **About** - Name, bio, photo, contact links (email copy, GitHub, phone)
- **News** - Latest updates
- **Publications** - Academic papers (CVPR 2026, RCAR 2025, etc.)
- **Experience** - Education
- **Projects** - Engineering and research projects
- **Awards** - Scholarships and honors

## Usage

```bash
git clone https://github.com/JunwuE/JunwuE.github.io.git
# Open index.html in browser, or:
python -m http.server 8000
```
